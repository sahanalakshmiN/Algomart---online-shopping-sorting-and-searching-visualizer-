## Algomart 

An interactive DSA visualization platform that demonstrates sorting and searching algorithms through an online shopping-style interface.

---

## Features

- Interactive sorting algorithm visualization
- Searching algorithm simulation
- Step-by-step execution display
- Algorithm speed comparison
- Shopping-inspired UI experience
- Real-time visualization of algorithm behavior

---

## Algorithms Implemented

### Sorting Algorithms
- Bubble Sort
- Merge Sort
- Quick Sort
- Insertion Sort

### Searching Algorithms
- Linear Search
- Binary Search

---

## Tech Stack

- TypeScript
- React
- Vite
- HTML/CSS
- Figma AI

---

## Project Purpose

This project was developed to make Data Structures and Algorithms more interactive and visually understandable through a modern shopping-style web interface.
